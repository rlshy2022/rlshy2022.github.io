恋爱组件使用手册示例

发表于2026-02-11|更新于2026-02-11|开发笔记
|浏览量:

这是一篇 示例文章，专门用来演示：时间轴、对话气泡、恋爱清单、提示块、图片写法等所有花里胡哨的样式，方便以后写文章随时照抄。

目录速查（写作菜谱）

  • 提示块 note：{% note info %}内容{% endnote %}，类型常见：info / warning / success
  • 恋爱清单（爱心打勾）：- [ ] 文本 / - [x] 文本（Markdown 任务列表）
  • 对话气泡（chat）：外层 div.chat-container，内部用 div.chat-item.left/right + div.chat-avatar + div.chat-content
  • 时间轴（love-timeline）：外层 div.love-timeline，每个节点是 div.love-timeline-item 包含 love-timeline-date + love-timeline-content
  • 普通图片：![描述文本](OSS地址?x-oss-process=image/format,webp)，务必写好 alt 描述
  • 相册图片：在 gallery.yml 里配置，前台自动套用 .gallery-items img 的圆角与 hover 效果

一、基础 Markdown 排版示例

1. 标题 & 文本

这是普通段落，可以正常使用 加粗、斜体、删除线、以及 链接示例。

2. 引用块（对应 blockquote 圆角样式）

斯人若彩虹，遇上方知有。
当我们把故事写进博客的那一刻，它们就有了永远。

3. 代码块（会被圆角美化）

二、提示块（Butterfly 的 note 组件）

1. Info 提示

这是一个 info 提示块，可以用来写温柔的旁白或小贴士。

2. Warning 提示

这是一个 warning 提示块，比如提醒“此处内容会让人嘴角上扬，请注意防甜”。

提示块的语法是：{% note 类型 %} 内容 {% endnote %}，类型常见有 info / warning / success 等。

三、恋爱清单（task-list 自动变爱心打勾）

在 Markdown 里写普通的任务列表：

  • 一起看一场日落
  • 去海边吹海风
  • 手牵手逛一次七里山塘
  • 一起做一顿晚餐
  • 写一封认真的小情书

注意：

  • 写法就是 - [ ] / - [x]，Hexo 生成后会加上 li.task-list-item 的 class，自动应用你自定义的爱心勾选动画。

四、对话气泡组件（chat 样式）

场景：还原一次聊天记录、心情对话、互相表白的片段。

直接在 Markdown 里写 HTML：

今天的晚霞好好看呀，有点想跟你一起看。
那就约定一下，下一次好看的晚霞，都当作我们一起看的。
好呀，那你可要说到做到(´▽`ʃ♡ƪ)

使用说明：

  • 外层容器：<div class="chat-container">
  • 每条对话：<div class="chat-item left"> 或 right（左是怡怡，右是欢欢）；
  • 头像：<div class="chat-avatar"><img ...></div>；
  • 内容：<div class="chat-content">聊天文字</div>。

五、时间轴组件（love-timeline）

场景：做一条「我们的旅程」时间线，记录一些关键节点。

2022-08-18
我们在某个夏天的傍晚，相遇在同一条时间线。
从那天起，世界开始有了粉色滤镜。
2025-12-31
第一次跨年旅行：景德镇。
火车、瓷器、街边的烟火气，还有一起窝在被子里聊天到很晚。
2026-01-XX
苏州的小巷和河边，留下了很多我们走过的脚印。
以后还会有更多日期，被慢慢写进这条时间轴里。

使用说明：

  • 外层：class="love-timeline"
  • 单个节点：class="love-timeline-item"
    • 日期：class="love-timeline-date"
    • 内容：class="love-timeline-content"

你也可以直接在 Markdown 中粘贴上面的 HTML 段落使用。

六、图片 & 相册写法建议

1. 普通插图（正文内）

这里是一段正文，上面讲了一段故事，下面配一张图：

建议：

  • 一定写上 alt 文本（上例里的 苏州的小巷和河边），对无障碍和 SEO 都更友好；
  • 图片地址尽量用 OSS 链接，带上 ?x-oss-process=image/format,webp，剩下的宽度压缩会由你写的 oss_optimize.js 自动完成。

2. 相册页（使用 Butterfly 内置 gallery）

相册页（如 /gallery/）通常由主题和 gallery.yml 自动生成，你只需要在 source/_data/gallery.yml 中配置图片列表即可。
不必手写 HTML，custom.css 已经对 .gallery-items img 做了圆角和 hover 发光的美化。

七、综合示例小节

下面是一个把 清单 + 时间轴 + 对话 混在一起的小节，仅作参考：

今天的心情记录（综合示例）

  • 早上互道早安
  • 一起云喝奶茶
  • 晚上视频见面
  • 记住今天发生的每一个小细节
早上
醒来第一件事，是看看手机里有没有你的消息。
中午
工作/上课的间隙，突然看到一张你发来的小照片，整个人一下子就软掉了。
今天也好想你呀。
我也是呀，再坚持一下，我们很快就又能见面啦。

以后如果你忘了某个「组件」的写法，可以直接打开这篇示例文章，把对应段落（时间轴、聊天、清单、提示块、图片）复制过去再改文案就好。
如果还想增加别的组件（比如「进度条」「标签云」「小卡片」），也可以继续在 custom.css + 小段 HTML 的方式上扩展。
